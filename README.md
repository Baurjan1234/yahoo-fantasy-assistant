# Personal Fantasy Basketball Assistant

A private, single-user tool for my own Yahoo Fantasy Basketball league (2026-27).

## What it does
- Reads my league's roster, free agents, matchups, and player stats (read-only)
- Shows simple daily reports to help me choose my lineup and waiver pickups

## Scope
- One user (me), one league
- Read-only, low request volume, results cached
- Non-commercial; data is not shared, sold, or published
